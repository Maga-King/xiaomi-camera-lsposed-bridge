# 完整成品的使用范围

Actions 产物是 **LSPosed 修复模块 APK**，不是把小米相机主程序改名而成的独立相机，也不是包含所有机型固件的通用 HAL。包含 M3/M9 模型、原生算法、QNN、原有美颜依赖和兼容参数，不需要从开发者电脑再拿漏装素材。

1. 备份原模块、相机设置和相片。需要 LSPosed 及兼容的小米相机，主要作用域 `com.android.camera`。
2. 公开 CI 使用新建的独立签名。若之前装了本地旧私钥签名版本，不能直接覆盖；备份后卸载旧模块，再装 CI APK。不要清空用户相册。
3. 激活模块，选择相机作用域，强停相机后重新进入；必要时按 LSPosed 要求重启。
4. M3/M9 本地链先验证主摄干净 12MP JPEG 输入。其代码具有尺寸、调用方、lux/CCT 和运行时条件，其他输入回退原图，不承诺任意焦段都运行同一算法。
5. 欧加 APS、设备 GPU/OpenCL/HTP、相机权限与 SELinux 仍由目标系统提供。不要跨 SoC 覆盖 vendor GPU/ISP 来强行满足依赖。

Release 中的 `companion/Camera-v29-m9-cloud-control.apk` 是历史 donor 配套参考，不证明它与每一台手机的系统签名、所有相机版本兼容。不要盲目覆盖现有系统相机，也不要把原始 donor 的其他小米专用模块整套刷到一加上。

云端编译成功只证明完整 APK 可构造、签名有效且必要资源未丢失；无法替代真实摄像头、服务器 AI 授权和所有拍摄模式验收。
